# Bug Reporter for BK

Backlogへのバグ報告・課題コメントをワンクリックで送信できるChrome拡張機能です。

---

## インストール方法

1. [Chrome ウェブストア](https://chromewebstore.google.com/detail/bug-reporter-for-bk/bpjjdjhlkjcpgjnkkfhjkmjdagicaokb) にアクセスする
2. 「Chromeに追加」をクリックしてインストールする
3. Chromeのツールバーに表示された拡張機能アイコンをクリックし、サイドパネルを開く

---

## 初期設定

1. サイドパネル右上の「設定」をクリックする
2. **スペースURL** に Backlog のスペースドメインを入力する（例: `yourspace.backlog.com` / `yourspace.backlog.jp`）
3. **APIキー** を入力する（Backlog の個人設定ページから取得）
4. 「接続テスト」で接続を確認する
5. 「保存する」をクリックする

---

## 使い方

詳細な使い方は、拡張機能のサイドパネル右上にある **「？」ボタン** から使い方ガイドを参照してください。

主な機能：

- **新規作成 / コメント** の2モードで Backlog に投稿
- 表示部分・フルページ・選択範囲の3種類のスクリーンショット（最大10枚添付）
- Backlog記法ツールバー（見出し・太字・斜体・打ち消し線・引用・コードブロック・テーブルなど）
- `@` メンション、環境情報の自動挿入
- **お知らせするユーザー** — ユーザーおよびチーム単位で通知先を任意追加
  - コメントモードで「この課題の参加者を追加」ボタンが表示され、Backlogの課題参加者を通知対象に一括追加可能
- よく使うプロジェクト・課題のピン留め（各最大3件）
- **Backlogページ連携** — Backlogの課題詳細ページのコメント入力欄に「👥 過去の参加者をメンション」ボタンを自動挿入。過去のコメント参加者をワンクリックで一括メンション可能
